# 設定とログ

[Deutsch](../de/05-settings.md) | [English](../en/05-settings.md) | [Español](../es/05-settings.md) | [Français](../fr/05-settings.md) | [Italiano](../it/05-settings.md) | [日本語](05-settings.md) | [한국어](../ko/05-settings.md) | [Polski](../pl/05-settings.md) | [Português (Brasil)](../pt-BR/05-settings.md) | [Русский](../ru/05-settings.md) | [中文](../zh/05-settings.md)

## 概要

Redmine MCP プラグインは標準の Redmine プラグイン設定インターフェースで構成されます。MCP 操作は追加でログに記録されます。

## 目的

管理者が MCP の有効化と個別プラグインの MCP 統合の有効化を制御できるようにすること。

## 影響範囲

- 設定
- UI
- プラグイン

## ビジネスルール

### 設定パラメータ

設定は **管理 → プラグイン → Redmine MCP → 設定** で利用可能です。

| パラメータ | デフォルト | 説明 |
|----------|--------------|----------|
| Enable MCP | オフ | `/mcp` エンドポイントを有効/無効にする。有効時、インストール済みプラグインの MCP 拡張が自動的に読み込まれる |
| Read-only mode | オフ | 書き込みツールと書き込みアクションをブロックする |
| MCP extensions | すべて有効 | MCP 統合を持つインストール済みプラグイン名の横のチェックボックス |

### UI の MCP 拡張

- 識別子リスト用のテキストフィールド（"Disabled extensions"）とインストール済みプラグインの参照リストは使用しない。
- 別途の自動読み込み拡張チェックボックスは使用しない。
- 代わりに、設定ページには MCP 統合を持つインストール済みプラグインのリストが表示される。
- プラグインは、自動読み込みと同じ規約で拡張ファイルを持つ場合 MCP 統合ありとみなされる（[04-extensions.md](04-extensions.md) 参照）。
- `redmine_mcp` プラグインはこのリストに表示されない。
- 各項目にはチェックボックスとプラグイン名がある。
- リストの凡例には、カスタムフィールドフォームのプロジェクトやトラッカーと同様に Check all / Uncheck all トグルがある。
- チェック済みボックスは、MCP 有効時にプラグインの MCP 拡張が読み込まれることを意味する。
- 未チェックボックスは、拡張ファイルが存在してもプラグインの拡張が読み込まれないことを意味する。
- インストール済みプラグインに MCP 統合がない場合、リストは空: 標準 Redmine の「データなし」メッセージが表示され、Check all / Uncheck all トグルは非表示になる。
- 以前保存された無効化プラグイン識別子は引き続き適用される: 対応するチェックボックスは未チェックで表示される。

### 設定変更時の動作

- MCP 無効化は `/mcp` へのすべてのリクエストを即座にブロックする（HTTP 503）。
- MCP 有効時、拡張は Redmine 起動時に読み込まれる。MCP 無効時、拡張の自動読み込みは実行されない。
- MCP 拡張チェックボックスの変更は Redmine 再起動後に有効になる。

## ログ

### 記録内容

- 拡張読み込みの開始と終了;
- ツール、リソース、プロンプトの正常登録;
- 既存ツールの拡張;
- 拡張の登録および読み込みエラー;
- ツール実行エラー;
- MCP およびツールのアクセス拒否。

### 形式

- メッセージは標準 Rails ログに書き込まれる。
- 各メッセージには `[redmine_mcp]` プレフィックスがある。
- 別途のログレベル設定は使用しない: プラグインはすべてのメッセージを書き込む。

## エッジケース

- すべての MCP 拡張チェックボックスが有効（または統合を持つプラグインがない）場合、MCP 有効時に見つかったすべての拡張が読み込まれる。
- MCP 拡張ファイルのないプラグインはリストに表示されず、これらの設定で無効化されない。
- プラグインが後から MCP 統合を取得した場合、以前無効化されていなければチェックボックスはデフォルトで有効になる。
- 保存済み無効化リストの未知または削除されたプラグイン識別子は無視される。
- 以前保存された拡張自動読み込みフラグは無視される: 拡張読み込みは Enable MCP に従う。
- 以前保存されたログレベルは無視され、設定保存時に削除される。
- Read-only mode 有効時、書き込みツールは（ユーザーが権限を持つ場合）`tools/list` に残るが、呼び出し時にエラーを返す; 複合ツールの読み取りアクションは引き続き動作する。

## エラー処理

- 設定エラーは Redmine 起動をブロックしてはならない。
- ログエラーは MCP リクエスト処理に影響しない。

## テストシナリオ

1. MCP 無効 — `/mcp` へのリクエストは HTTP 503 を返す。
2. MCP 有効 — リクエストが処理される。
3. MCP 統合のチェックが外れたプラグイン — 再起動後そのツールは存在しない。
4. 設定ページにログレベルフィールドはない; MCP メッセージは Rails ログに書き込まれる。
5. 設定ページには MCP 統合を持つインストール済みプラグインの名前のみ表示される; 各項目にチェックボックスがある。
6. MCP 統合のないプラグインは設定ページに表示されない。
7. MCP 無効時、他プラグインの拡張は起動時に読み込まれない。
