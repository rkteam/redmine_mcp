# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of Redmine MCP.

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| Older versions | No |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub Private Vulnerability Reporting to report security issues privately.

When reporting a vulnerability, please include, where applicable:

- the affected Redmine MCP version;
- the Redmine and Ruby versions;
- steps to reproduce the issue;
- the expected and actual behavior;
- the potential security impact.

Do not include real API keys, credentials, personal data, or other secrets
in reports or logs.
